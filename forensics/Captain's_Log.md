## Challenge Name: Captain's Log
**Category:** forensics
**Points:** 400
**Solves:** 11

Challenge Description: 
In this challenge, we need to find the flag hidden in a captain's log. The log is a text file that contains various entries about the captain's journey but no explicit flag. We need to analyze the log and find the hidden flag.

Artifact Files:
* [captains_log.png](./artifact/captains_log.png)

### Approach

**1. Strings analysis**

To analyze the .png file, I used an online forensics tool (forensically) that has a tool for strings analysis. This tool allows us to extract any readable strings from the image file. By analyzing the extracted strings we can find the hidden flag.


### Reflections
A reminder that image often hides some secrets in CTF challenges.
