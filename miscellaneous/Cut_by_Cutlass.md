## Challenge Name: Cut by Cutlass
**Category:** Miscellaneous
**Points:** 484
**Solves:** 5

Challenge Description: 
In this challenge, we are given a zip file named `challenge.zip` that contains multiple images representing a scroll that has been cut into puzzle pieces. Our task is to reconstruct the scroll by arranging the pieces in the correct order and orientation to reveal the hidden message.

Artifact Files:
* [challenge.zip](./artifact/challenge.zip)

### Approach

**1. Manually reconstruct the scroll with GIMP**

To solve this challenge, we can use an image editing software like GIMP to manually reconstruct the scroll. We will need to import all the images from the zip file into GIMP and then arrange them in the correct order and orientation to form the complete scroll.

### Reflections
This challenge was fun and creative. It required a bit of patience and attention to detail to piece together the scroll correctly. It is not very technical, even though it could be solved using more advanced techniques like image processing or machine learning, but it was a nice change of pace from the more technical challenges.
